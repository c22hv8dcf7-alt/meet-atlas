L

Linux — download

The Linux edition is real: v0.1.0, a small download that installs per-user — no sudo, no account. On first run the Fit Check sizes Atlas to your machine (6 GB RAM floor). Unpack it, run linux/install.sh, then type atlas. One prerequisite: Atlas chats through Ollama — install it from ollama.com and pull the model the Fit Check names; without it, Atlas opens and tells you exactly what’s missing.

Free software, kept free on purpose

Atlas has no subscription because it has no server to pay for — it lives on your Mac. What it does have is one developer, a test Mac, and time. If Atlas saves you the price of a subscription — or a $114.99 stick — and you’d like to help it stay free for the next person, you can chip in here.

Support is voluntary and changes nothing about what you get: the free Atlas is the whole Atlas. There is no paid tier, and there never will be a version where the free one is crippled to upsell you.

Tip jar opening soon

Plain words about money: Porch Light is not a registered charity, so support is not tax-deductible, and it counts as income for the publisher. It is a gift toward keeping free software free — never a purchase, and gifts can’t be refunded once given — please only chip in if you’re sure. Thank you for even reading this far down the page.
