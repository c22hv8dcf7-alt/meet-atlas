# Meet Atlas

**Website: https://c22hv8dcf7-alt.github.io/meet-atlas/**

Atlas is a free local AI assistant: it runs offline on your own machine, with persistent, plain-file memory you can read and edit, and cited answers from your own documents — it says "I don't know" when it doesn't have a source.

No account. No subscription. No cloud.

This repository also hosts the Meet Atlas website (GitHub Pages).
