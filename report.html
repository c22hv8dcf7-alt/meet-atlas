Report a copy

Found Atlas somewhere it shouldn't be?

Atlas is free — from this site, and only from this site. If you found it anywhere else, that wasn't us, and telling us helps everyone.

What counts

Someone selling Atlas — for any price, on any drive, in any bundle. Atlas is never sold, by anyone, ever.

A download offered anywhere else — a mirror, a file host, a torrent, another store. The only authorised downloads are this website and the releases it links to.

Atlas wearing another name or face — the same software renamed or rebranded. Changed copies don't get to call themselves Atlas.

Your own copy told you it was modified. Genuine Atlas checks its own seal at launch. If it ever refuses to run because it was changed, it didn't come from us — the real one is free here.

What to send

The link, first of all. A screenshot if you have one, and a word about where you found it. Please don't buy or download anything from them to test it — the link is enough.

Reports go to a public tracker (so the record is open) and every one is read by a human at Porch Light. We never ask a reporter for anything beyond what they choose to send.

Open a copy report

What happens next: we verify the report, then ask the host to take the copy down — the Atlas Free-Use License names this site as the only authorised source, and hosts act on that. If a report turns out to be a misunderstanding, nothing happens to anyone; we'd rather hear about it than not.
